# Email Finder & Verifier API – code examples

Examples for every Email Finder & Verifier endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |

| cURL (Bash) | [`curl/finder.sh`](curl/finder.sh) | `bash finder.sh` |
